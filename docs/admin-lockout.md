# 管理者認証の一時遮断

- 対象URLは変更しない。`/admin`、`/admin/**`、`/api/admin`、`/api/admin/**` とBasic認証での免許証画像取得を同じMiddlewareで保護する。一般公開ページ・通常のユーザー認証は遮断しない。
- 管理者Basic認証に失敗した入力をIPによらず合算。直近60秒に100回目の失敗があった時点で全管理者を30分間遮断する。認証情報なしの初回チャレンジや認証成功はカウントしない（ブラウザは認証成功後も各リクエストに認証情報を付けるため）。
- 遮断中は正しい認証情報でも503とRetry-After、no-storeを返す。アクセスが続いても期限を延ばさない。30分経過後に自動解除。
- `ADMIN_BASIC_USER` と `ADMIN_BASIC_PASS` の明示設定が必須。未設定時は503で拒否し、ソース内の既定パスワードを使わない。HTTPSを使う。
- カウンターはMiddlewareの実行コンテキスト内のメモリに保持する。単一プロセスでの運用を前提とし、PM2の当該アプリ再起動やEC2再起動でリセットされる。複数インスタンス・複数ワーカー・サーバーレスの全体同期は保証しない。ランタイムがコンテキストを再生成した場合もリセットされるため、厳密な全体遮断が必要なら共有ストア等を使う必要がある。
- 故意の100回の失敗で第三者も全管理者を締め出せる。要件上のトレードオフであり、認証・VPN/IP制限・MFAの代替にはならない。
- 発行済みのS3署名URLは最大60秒、表示済み/保存済みのページや画像はこの遮断では取り消せない。
- 公開解除API `/api/unblock` は従来のIP制限用で、この管理者遮断を解除できない。

検証: 100回の境界、60秒のローリング窓、30分の期限、期限延長なし、再起動相当のリセット、管理API保護、正しい管理者も遮断、一般ページへの影響なしをテストする。本番反映は別途必要。
